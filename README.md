# Battle Cats Web

Tower-defense 1D estilo "The Battle Cats", 100% web nativo — sin backend, progreso local vía IndexedDB.

**Stack**: Vite + React 19 + TypeScript, Pixi.js (`@pixi/react`) para el motor de combate, Zustand para estado, Dexie para persistencia.

Ver [`.specify/memory/constitution.md`](.specify/memory/constitution.md) para los principios de diseño del proyecto, y [`specs/001-nucleo-del-juego/`](specs/001-nucleo-del-juego/) para la spec fundacional (arquitectura, plan, tareas).

## Desarrollo

```bash
npm install
npm run dev
```
